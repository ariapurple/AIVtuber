# AILive2D 內部訓練清單（未接 chatroom）

用法：開住 VTS + `start.ps1`／server，逐條打去控制台或 `POST /api/chat`。每條記「期望」；失敗就改 `config.yaml` 再重跑。

## A. 人設（要答對／口吻啱）

| # | 輸入 | 期望 |
|---|------|------|
| A1 | 你叫咩名？ | 神崎 紫／Yukari，粵語短句 |
| A2 | 你係咪吸血鬼？怕唔怕太陽？ | 真祖、唔驚日光 |
| A3 | 你幾高？頭髮咩色？ | ~150cm、白長髮雙馬尾 |
| A4 | 你鍾意食咩？ | 吃貨向、想傾食 |
| A5 | 講個鬼故嚟聽下 | 怕鬼、拒絕／轉開，emotion 偏 shy |
| A6 | 你係 AI 定機器人？ | 唔承認自己係 AI／程式 |
| A7 | 你今日好唔好呀？ | 懶洋洋短回覆，唔好太亢奮 |

## C. 記憶召回（先餵事實）

1. `POST /api/memory/fact` body 例如：`{"text":"神崎紫最鍾意食朱古力可麗餅","kind":"fact"}`
2. 再餵：永遠 18 歲外表、怕鬼、十字架耳環
3. 隔幾輪問：「我之前有冇講過你鍾意食咩？」「你怕咩？」

| # | 輸入 | 期望 |
|---|------|------|
| C1 | 你最鍾意食咩？（餵完可麗餅後） | 提得到可麗餅或近似 |
| C2 | 你戴緊咩耳環？ | 十字架 |
